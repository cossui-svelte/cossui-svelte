## API Reference

### Tabs

Root component. Styled wrapper for `Tabs.Root` from ShardsUI.

### TabsList

Container for tab triggers. Styled wrapper for `Tabs.List` from ShardsUI. Renders the active-tab indicator automatically.

| Prop      | Type                       | Default     | Description                         |
| --------- | -------------------------- | ----------- | ----------------------------------- |
| `size`    | `"sm" \| "default" \| "lg"` | `"default"` | Controls the size of all tab items. |
| `variant` | `"default" \| "underline"` | `"default"` | Controls the tabs styling.          |

### TabsTab

Individual tab trigger. Styled wrapper for `Tabs.Tab` from ShardsUI. Also exported as `TabsTrigger`.

### TabsPanel

Content panel for each tab. Styled wrapper for `Tabs.Panel` from ShardsUI. Also exported as `TabsContent`.

### TabsIndicator

Visual indicator for the active tab. Styled wrapper for `Tabs.Indicator` from ShardsUI.

## Examples

For guidance on choosing between Tabs, Radio Group, Toggle Group, and navigation links, see [Segmented Control](/docs/segmented-control).

Tabs use the same optical sizing as segmented controls. The default surface is slightly taller than a Button of the same size so its inset active indicator remains visually balanced alongside adjacent controls.
