## Usage

Create an editor with `createEditor`, then pass it to `RichEditor` and compose the parts you need as children.

```svelte
<script lang="ts">
  import { createEditor, RichEditor } from '#lib/components/ui/rich-editor';

  const editor = createEditor({
    onUpdate: () => console.log(editor?.getJSON())
  });
</script>

<RichEditor {editor}>
  <RichEditor.Toolbar />
  <RichEditor.Content />
  <RichEditor.BubbleMenu />
  <RichEditor.DragHandle />
</RichEditor>
```

`createEditor` returns `undefined` during SSR, so guard any direct use of `editor` (for example `editor?.commands.setContent(...)`).

## API Reference

### createEditor

Creates a Tiptap editor preconfigured with the default extensions (starter kit, tables, task lists, math, mermaid, code blocks, callouts, media and slash commands).

| Option          | Type                              | Default | Description                                                              |
| --------------- | --------------------------------- | ------- | ------------------------------------------------------------------------ |
| `extensions`    | `Extensions`                      | `[]`    | Extra Tiptap extensions appended to the defaults                         |
| `onUpdate`      | `() => void`                      | -       | Called whenever the document changes                                     |
| `collaborative` | `boolean`                         | `false` | Disables built-in history so Yjs collaboration can manage undo and redo  |
| `onFileUpload`  | `(file: File) => Promise<string>` | -       | Uploads a dropped, pasted or selected media file and returns its URL     |

### RichEditor

Provides the editor to its children through context.

| Prop     | Type                | Default | Description              |
| -------- | ------------------- | ------- | ------------------------ |
| `editor` | `Editor`            | -       | The editor from `createEditor` |

### RichEditor.Content

Renders the editable document, plus the link, math and table menus.

### RichEditor.Toolbar

A ready-made toolbar with undo/redo, headings, formatting, alignment, lists, media, colors and export.

### RichEditor.BubbleMenu

A floating menu shown when text is selected.

### RichEditor.DragHandle / RichEditor.DragHandleExtended

Block drag handles. The extended variant adds a block menu.

### RichEditor.ToC

A table of contents that updates as headings are added.

### Custom toolbars

The toolbar actions are exported as `commands` from `#lib/components/ui/rich-editor/commands`, each with an `onClick`, `isActive` and `clickable` function. Use them with `useEditorTransaction` to build your own toolbar, as the examples below do.
