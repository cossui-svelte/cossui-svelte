## About

A segmented control is a visual pattern, not a standalone behavior. `SegmentedControl` and `SegmentedControlItem` provide the presentation and the sliding indicator; the element you render through their `child` snippet provides the semantics, keyboard interactions, and state model.

## Choose the right primitive

| Intent | Use | Why |
| ------ | --- | --- |
| Choose one value in a form | [Radio Group](/docs/radio-group) | Represents a mutually exclusive value and participates in form state. |
| Navigate to another URL or route | Navigation links | Preserves link behavior, browser history, and `aria-current`. |
| Apply an exclusive filter or mode | [Toggle Group](/docs/toggle-group) | Represents the pressed state of an action that may be cleared. |
| Switch between related panels | [Tabs](/docs/tabs) | Connects each tab to an associated content panel. |

Choose the primitive from the interaction first, then render it through the segmented control. Visual similarity alone is not a reason to use Tabs or Toggle Group.

## Usage

```svelte
<script lang="ts">
  import { RadioGroupPrimitive, RadioPrimitive } from '#lib/components/ui/radio-group';
  import { SegmentedControl, SegmentedControlItem } from '#lib/components/ui/segmented-control';
</script>

<SegmentedControl aria-label="Billing period">
  {#snippet child({ props, content })}
    <RadioGroupPrimitive {...props} value="monthly">{@render content()}</RadioGroupPrimitive>
  {/snippet}
  <SegmentedControlItem>
    {#snippet child({ props })}
      <RadioPrimitive.Root {...props} value="monthly">Monthly</RadioPrimitive.Root>
    {/snippet}
  </SegmentedControlItem>
  <SegmentedControlItem>
    {#snippet child({ props })}
      <RadioPrimitive.Root {...props} value="yearly">Yearly</RadioPrimitive.Root>
    {/snippet}
  </SegmentedControlItem>
</SegmentedControl>
```

Spread `props` on your element and put behavior props such as `value`, `onValueChange`, or `href` on it. On the root, render `content` inside your element: it holds the items plus the sliding indicator. Use the Radio Group primitives rather than `RadioGroup` and `Radio`, so the native radio indicator is not rendered.

The same composition works for navigation links:

```svelte
<SegmentedControl aria-label="Project sections">
  {#snippet child({ props, content })}
    <nav {...props}>{@render content()}</nav>
  {/snippet}
  <SegmentedControlItem>
    {#snippet child({ props })}
      <a {...props} aria-current="page" href="/overview">Overview</a>
    {/snippet}
  </SegmentedControlItem>
  <SegmentedControlItem>
    {#snippet child({ props })}
      <a {...props} href="/activity">Activity</a>
    {/snippet}
  </SegmentedControlItem>
</SegmentedControl>
```

And for an exclusive filter that may be cleared:

```svelte
<SegmentedControl>
  {#snippet child({ props, content })}
    <ToggleGroupPrimitive {...props} aria-label="Status">{@render content()}</ToggleGroupPrimitive>
  {/snippet}
  <SegmentedControlItem>
    {#snippet child({ props })}
      <TogglePrimitive {...props} value="open">Open</TogglePrimitive>
    {/snippet}
  </SegmentedControlItem>
  <SegmentedControlItem>
    {#snippet child({ props })}
      <TogglePrimitive {...props} value="closed">Closed</TogglePrimitive>
    {/snippet}
  </SegmentedControlItem>
</SegmentedControl>
```

## API Reference

### SegmentedControl

The segmented surface. Renders a `<div>` by default and appends the sliding indicator after its children. Provides the size to its items via context.

| Prop    | Type                                                | Default     | Description                                                                                         |
| ------- | --------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------- |
| `size`  | `"sm" \| "default" \| "lg"`                         | `"default"` | Controls the height and horizontal padding of every item                                            |
| `child` | `Snippet<[{ props, content }]>`                     | —           | Replaces the rendered element, for example with a Radio Group primitive or `<nav>`. Render `content` inside it |

### SegmentedControlItem

A single segment. Renders a `<button type="button">` by default.

| Prop    | Type                        | Default             | Description                                                       |
| ------- | --------------------------- | ------------------- | ----------------------------------------------------------------- |
| `size`  | `"sm" \| "default" \| "lg"` | Inherited from root | Overrides the size inherited from `SegmentedControl`              |
| `child` | `Snippet<[{ props }]>`      | —                   | Replaces the rendered element, for example with a radio or a link |

An item is active when it has `data-checked` (Radio Group), `aria-current="page"` (links), or `data-pressed` (Toggle Group). The indicator slides to the active item over 200ms with an ease-in-out curve, stays still when the user prefers reduced motion, and is hidden when no item is active. Before hydration or without JavaScript, the active item paints its own static pill instead. For navigation, the pill animates only when the control persists across route changes, such as in a shared layout; otherwise it appears in place on each page.

At the outside edges, the item padding and the surface's inset combine to match the horizontal padding of the corresponding Button size. The surface is slightly taller than that Button to optically balance its inset selected item when the controls appear next to each other.

## Related content

Use Tabs when each segment controls an associated content panel. Tabs keep ShardsUI's own indicator and add orientation support and panel semantics, but share the segmented control's sizes, icon layout, and indicator surface so both look the same.
